# Pegasus — Figure Generation

This directory provides the code for generating the figures in the paper. It is important to note that all experimental data in the paper were obtained from real hardware tests and thus cannot be reproduced through software simulation. Therefore, the reproduction scripts we provide generate the figures directly from the final hardware-collected results, rather than from simulated software data.

---

## Table Data
All table data have been provided in our paper and in the submitted LaTeX archive. Users can refer to those directly.

## 📂 Figure 8
Simply run `python ./code/Figure8.py` to generate the result. The output will be available at `./figures/Figure8.pdf`.
